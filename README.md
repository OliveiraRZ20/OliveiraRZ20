## Sobre Mim

Estudante de Engenharia da Computação e atuando como Analista de Desenvolvimento de Sistemas Jr na Bradesco Seguros. Meu foco é projetar soluções que unem análise de dados, engenharia em cloud e automação inteligente para resolver problemas de negócios e otimizar processos corporativos.

Atualmente, busco criar pontes entre a engenharia de software tradicional e o ecossistema de dados, explorando desde a construção de rotinas ETL até a integração de inteligência artificial personalizada.

---

## 🚀 O que eu faço

- 💻 **Desenvolvimento Python:** Criando sistemas orientados a objetos e rotinas de dados (padrão MVC).
- ☁️ **Engenharia de Dados & Cloud:** Processamento de dados e orquestração de pipelines usando **PySpark**, **Azure Data Factory** e **Databricks**.
- 📊 **BI & Data Analytics:** Desenvolvimento e automação de dashboards corporativos com **Power BI** e **Looker Studio**.
- 🤖 **IA & Automação:** Criação de agentes GPT personalizados para automatização e atendimento.
